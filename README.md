# anmolgoel.me

Source of [anmolgoel.me](https://anmolgoel.me), Anmol Goel's portfolio: Biotech × AI (IIT Delhi).

Built with React, Vite, Tailwind CSS and Framer Motion. All content lives in [`src/data/profile_data.json`](src/data/profile_data.json); the components in `src/components/` just render it.

```bash
npm install
npm run dev       # local preview
npm run build     # production build in dist/
npm run deploy    # publish dist/ to the gh-pages branch (custom domain via public/CNAME)
```
